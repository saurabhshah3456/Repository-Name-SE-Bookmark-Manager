# Privacy Policy

SE Bookmark Manager is a Microsoft Edge extension that allows users to save, organize, search, categorize, export, import, and synchronize bookmarks.

## Data Storage

SE Bookmark Manager stores bookmark data inside the signed-in user's Microsoft OneDrive App Folder using Microsoft Graph.

Stored information may include:

- Bookmark title
- Bookmark URL
- Category
- Tags
- Notes
- Favorite status
- Creation and update timestamps

## Authentication

Users authenticate using Microsoft Entra ID through Microsoft's OAuth authorization platform.

The extension uses delegated Microsoft Graph permissions granted by the user.

## Data Sharing

SE Bookmark Manager does not sell, transfer, lease, share, or distribute user data to third parties.

Bookmark information remains under the control of the signed-in user within their Microsoft 365 tenant and OneDrive environment.

## Tracking

SE Bookmark Manager does not:

- Track browsing history
- Monitor user activity
- Record keystrokes
- Collect location data
- Serve advertisements
- Perform behavioral profiling
- Collect financial information
- Collect health information

## External Services

The extension communicates only with Microsoft services required for authentication and bookmark synchronization, including:

- login.microsoftonline.com
- graph.microsoft.com
